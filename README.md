# Mi Tienda

Tienda de videojuegos desarrollada para el caso semestral de DSY1104.

El proyecto parte de una plantilla en HTML, CSS, JavaScript y Bootstrap (con un carrito de compras en JavaScript) y se va a migrar a **React con Next.js**: componentes, navegación, formularios con validación y pruebas de los componentes.

## Ramas

- `main`: versión final y estable.
- `Desarrollo`: rama donde se integran las tareas terminadas.
- `tarea/...`: una rama por cada tarea, creada desde `Desarrollo`.
